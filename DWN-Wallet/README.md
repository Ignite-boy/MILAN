# Natively DWN Wallet

A native-oriented **DWN wallet and user account prototype** within the MILAN ecosystem.

## Role in the MILAN ecosystem

The wallet explores how identity, data, and user-controlled digital assets can work together instead of being trapped inside one centralized platform.

### Ecosystem relationship

- **MILAN App** — decentralized social application at the repository root
- **DWN** — decentralized data layer and infrastructure in `../DWN`
- **Natively DWN Wallet** — wallet, account, and user-side DWN interaction layer in this folder
- **Live UI Update** — production-facing interface in `../Live-UI-Update`

## Focus

- User accounts
- DWN-native data
- Identity-aware interactions
- Transactions and wallet flows
- Future integration with decentralized application experiences

This project remains a prototype; future integration should be validated before production use.
