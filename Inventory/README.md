# MILAN SEO Inventory

Production-oriented SEO inventory and monitoring for https://milanlife.in.

## Goal
Track the public search surface for decentralized social media, privacy, DWN, DID, Web5 and related topics without creating doorway pages or mass low-value content.

## What it does

- Crawls the public site and sitemap.
- Inventories indexable URLs and technical SEO signals.
- Detects missing title, meta description, canonical, robots, Open Graph, JSON-LD, H1 and image alt signals.
- Detects broken/non-HTML sitemap URLs.
- Produces a JSON report suitable for CI artifacts and later trend analysis.
- Runs automatically on GitHub Actions and can be dispatched manually with a target URL.

## Important

This is an audit/recommendation engine, not a ranking manipulation system. Search rankings are not guaranteed. Content should be useful, original and intended for people.
