Questions

Web5, without the mystery.

What is decentralized social media?

It is social networking designed so identity and data are not permanently locked inside one centralized platform. MILAN uses DID and DWN concepts to build around user control.

What does DID mean?

DID stands for Decentralized Identifier. It is a decentralized identity primitive used as part of the Web5 model.

What does DWN mean?

DWN stands for Decentralized Web Node. Think of it as a personal data layer where records can be managed with ownership and permissions in mind.

Can I use MILAN from anywhere in India?

Yes. MILAN is a web application, so the same product is available across India wherever you have an internet connection.
