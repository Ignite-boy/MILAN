Questions

Storage upgrade FAQ.

Does upgrading create a new MILAN account?

No. The storage quota is attached to the existing MILAN account.

What is different between 500 MB and 1 GB?

The main difference is capacity: 500 MB provides five times the Free quota, while 1 GB provides ten times the Free quota.

Are extra social features included in the paid plans?

The current plans are storage upgrades. The documented difference between the tiers is storage capacity, not a separate set of social features.

How is the payment verified?

This testing flow uses Cashfree Checkout with automatic server-side payment verification.

What happens after approval?

Your account's storage quota is updated to the selected plan.
