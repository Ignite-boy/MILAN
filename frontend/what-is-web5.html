MILAN × WEB5

How MILAN uses Web5 concepts

A Decentralized Web Node social network can separate personal data from a central platform by giving each person a dedicated data layer and greater control over access.

Web5 connects decentralized identity, Decentralized Web Nodes, and user-controlled data. These concepts can support a DID social network and a DWN social network where people control their digital context.

MILAN is designed as a social experience around decentralized identity, DWN-based data architecture and permission-aware sharing. The goal is to make the relationship between people, identity and data more explicit.

QUESTIONS

Web5 questions, answered

What is Web5 in simple words?

Web5 is a way to build apps where users can keep greater control over identity and data using decentralized identity and data infrastructure such as DID and DWN.

What is a DWN?

A Decentralized Web Node is a data infrastructure component that can store and expose records according to an application's identity and permission model.

What is a DID?

A Decentralized Identifier is an identifier designed for decentralized identity systems and can be controlled through cryptographic mechanisms.

How does MILAN relate to Web5?

MILAN uses Web5-oriented concepts including DID and DWN in its model for a privacy-focused social application.
